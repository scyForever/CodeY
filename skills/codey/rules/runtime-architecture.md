# Runtime architecture

`cli.py` builds `WorkspaceContext`, a provider-client factory, `SessionStore`, and `CodeYAgent`. `CodeYAgent` owns tools, memory, skills, hooks, stable prompt state, and the rule-supervised `CognitiveLoop`. `AgentLoop` is one LangGraph `StateGraph` template with `initialize -> think -> reflect -> act/fork -> finalize` routing. `fork_join` creates isolated, bounded, read-only child `CodeYAgent` instances that run the same graph under distinct `thread_id` values; `ForkCoordinator` performs an all-settled structured join. `ContextManager` adds the selected route, memory, active or shadow patch guidance, transcript, and current request. Every action still passes through `ToolExecutor`, and finalization preserves trace/outcome/root-cause/patch ordering. The optional hybrid evolution advisor receives only evidence-id-backed reduced traces; rules still arbitrate outcomes, candidate scope, and every Safety Gate transition. Sessions, checkpoints, traces, reports, branch results, durable memory, and evolution patches live below `.codey/`.
